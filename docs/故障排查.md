# 故障排查：8GB 卡的六种「不是报错」的故障

这些故障的共同点：**程序不崩溃、日志无异常，但速度或行为不对**。按出现频率排序。

---

## 1. 速度骤降（30 → 5-10 tok/s），但不报错

**症状**：模型正常回答，就是慢了两三倍。

**原因**：显存被抢占，部分层被卸载到 CPU，逐 token 走 PCIe。

**排查**：
```bash
nvidia-smi --query-gpu=memory.used,memory.free --format=csv,noheader
```
剩余显存 < 500MB 而模型本该有余量 → 有别的进程在吃显存。

**常见元凶**：ComfyUI（约 1.9GB）、浏览器硬件加速、另一个推理后端没关干净。

**处理**：`nvidia-smi` 看进程，关掉不用的；或给 llama-swap 设 `ttl`，让它空闲时自动卸载。

---

## 2. 上下文开到 128K，预填充突然慢 40 倍

**症状**：80K 时预填充 2,000+ tok/s，改到 128K 掉到 63 tok/s。

**原因**：KV 缓存超出显存，预填充阶段要在显存/内存间反复搬运。

**处理**：
- 降到 80K（8GB 卡安全上限）
- 或改用真正的长上下文方案（KV 外置/分页），接受有损恢复
- 确认 KV 是 4-bit：`--cache-type-k q4_0 --cache-type-v q4_0`

---

## 3. 视觉（多模态）一开就启动失败

**报错样式**：
```
requested Engine runtime reservation requires 1435013633 bytes,
but only 692060160 bytes are available
```

**原因**：视觉塔需要额外约 1.4GB 运行时预留，8GB 卡放不下。

**处理**：视觉走 CPU。慢几秒，但 0 显存开销。

---

## 4. 长驻服务「莫名消失」，日志干净

**症状**：引擎跑了几小时（有时只有几分钟）后消失，`tasklist` 里没有，事件日志无崩溃记录，无 WER 报告。

**原因**：进程不是崩溃，是被**回收**——某些 IDE / 任务运行器 / 自动化工具会清理自己启动的进程树。

**排查步骤（按顺序）**：
```powershell
# 1. 系统是否重启过？
(Get-CimInstance Win32_OperatingSystem).LastBootUpTime
# 2. 是否有崩溃记录？
Get-WinEvent -FilterHashtable @{LogName='Application'; Id=1000,1002} -MaxEvents 10
# 3. 有无意外断电（关键）
Get-WinEvent -FilterHashtable @{LogName='System'; Id=41,1074,6008,524}
```

**处理**：把长驻服务从自动化工具里拿出来——双击独立窗口启动，或注册为计划任务。本仓库的 `start-engine.bat` 就是干这个的。

---

## 5. 笔记本突然关机，日志只有一条 1074

**真实案例**（本机发生过一次）：夜间跑 benchmark，凌晨机器关机，日志里没有崩溃、没有蓝屏，只有：

```
Event 524 Kernel-Power: 电池触发器条件得到满足（Critical）
Event 1074 User32: winlogon 代表 SYSTEM 启动「关闭电源」
```

**解释**：电源适配器过热触发保护（或接触不良）→ 停止供电 → 笔记本静默切到电池 → 电池耗尽 → 系统按「关键电池动作=关机」自动关机。

**排查顺序**：
1. 摸适配器温度（满载时烫到不能长时间握持 = 有问题）
2. 检查 DC 头与机身插孔有无发黑、松动
3. `powercfg /batteryreport` 看电池健康度（设计容量 vs 满充容量）

**预防**：
- 长任务前确认电源插稳，适配器放在硬质开放平面（别塞抽屉、别压被子）
- 把「关键电池操作」从「关机」改成「休眠」，没电也能保住现场

---

## 6. 显存够但启动失败，报 CUDA 相关错误

**可能原因**：CUDA Graph 与混合精度推理不兼容。

**处理**：加 `--no-cuda-graph`（本机某款融合引擎的**必需**项，不加必启动失败）。

---

## 附：一个能省半小时的检查清单

跑长任务前 30 秒过一遍：

- [ ] `nvidia-smi` 剩余显存 > 模型体积 + 2GB
- [ ] 电源已插稳，适配器不烫
- [ ] ComfyUI / 其他推理后端已关
- [ ] 上下文设置 ≤ 80K（除非确实需要长窗口）
- [ ] KV 是 4-bit
- [ ] 服务是独立窗口启动的，不是被工具托管的
